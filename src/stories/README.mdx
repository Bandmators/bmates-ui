# bmates-ui

<br />

## Install

```
npm i bmates-ui
```

<br />

## How to use?

<br />

### Stylesheet

Import the stylesheet once at your application entry. It includes the component
styles, global base styles, and default design tokens.

```jsx
import 'bmates-ui/style.css';
```

`BMatesProvider` remains available as a deprecated compatibility wrapper, but
it no longer injects styles.
