# 시작하기

BMates UI는 Bandmators 제품을 위한 React 컴포넌트 라이브러리입니다.

## 설치

```bash
pnpm add bmates-ui
```

## 스타일시트

엔트리에서 스타일시트를 한 번 불러옵니다.

```tsx
import 'bmates-ui/style.css';
import { Button } from 'bmates-ui';
```

React 18 또는 19와 React DOM이 peer dependency로 필요합니다.

## 다음 단계

- 공통 인터페이스 원칙은 [접근성](/ko/guide/accessibility)에서 확인합니다.
- 색상과 간격 체계는 [디자인 토큰](/ko/guide/tokens)에서 확인합니다.
- 첫 컴포넌트로 [Button](/ko/components/button)을 살펴봅니다.
