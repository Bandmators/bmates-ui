# 시작하기

BMates UI는 Bandmators 제품을 위한 React 컴포넌트 라이브러리입니다.

## 설치

```bash
pnpm add bmates-ui
```

## 스타일시트

엔트리에서 스타일시트를 한 번 불러옵니다.

```tsx
import 'bmates-ui/style.css';
import { Button } from 'bmates-ui';
```

React 18 또는 19와 React DOM이 peer dependency로 필요합니다.
