# Input

텍스트와 기타 값을 입력하는 한 줄 입력 필드입니다.

## 가져오기

```tsx
import { Input, InputDesc, InputGroup / InputFile } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Input type="email" placeholder="you@example.com" aria-label="Email address" />
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Input`
:type: `React.ComponentPropsWithoutRef<'input'>`
`type`, `value`, `defaultValue`, `placeholder`, `disabled`, `required`, `onChange`를 포함한 모든 네이티브 input 속성을 지원합니다.
:::
::: api-item
:property: `InputFile.accept`
:type: `string`
허용할 파일 유형입니다. 다른 네이티브 input 속성도 전달됩니다.
:::
::: api-item
:property: `InputDesc`
:type: `p props`
도움말 또는 유효성 검사 문구입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
