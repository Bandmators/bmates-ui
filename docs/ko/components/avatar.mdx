# Avatar

사람이나 대상을 나타내는 이미지, 이니셜 또는 대체 콘텐츠입니다.

## 가져오기

```tsx
import { Avatar } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Avatar src="https://i.pravatar.cc/96?img=12" alt="Jane Doe" />
```

## 주요 속성 미리보기

아래 예제에서는 시각적 결과나 상호작용을 바꾸는 주요 속성을 각각 확인할 수 있습니다.

### 크기

:::: playground[크기]{isolation="inline"}
<ClientPreview name="bmates-preview" props={{ component: "avatar", example: "sizes" }} minHeight={132} />
```tsx
<Avatar src="/avatar.png" alt="Profile" size="lg" />
```
::::

## 컴포넌트 API

:::: api-list
::: api-item
:property: `src`
:type: `string`
필수 이미지 소스입니다.
:::
::: api-item
:property: `alt`
:type: `string`
필수 접근성 대체 텍스트입니다.
:::
::: api-item
:property: `size`
:type: `xs` | `sm` | `md` | `lg` | `xl`
:default: `md`
렌더링할 아바타 크기입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
