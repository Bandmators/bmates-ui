# Accordion

관련 콘텐츠를 접고 펼쳐 한 번에 필요한 내용만 보여주는 섹션입니다.

## 가져오기

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
{/* One item may be open at a time. */}
<Accordion defaultValue="account">
  <AccordionItem value="account">
    <AccordionTrigger>Account</AccordionTrigger>
    <AccordionContent>
      Manage your profile and notification settings.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="billing">
    <AccordionTrigger>Billing</AccordionTrigger>
    <AccordionContent>View invoices and payment methods.</AccordionContent>
  </AccordionItem>
</Accordion>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `type`
:type: `single` | `multiple`
:default: `single`
하나 또는 여러 항목을 동시에 열 수 있도록 설정합니다.
:::
::: api-item
:property: `defaultValue`
:type: string | string[]
처음 열어 둘 항목의 값입니다. `multiple`에서는 문자열 배열을 사용합니다.
:::
::: api-item
:property: `AccordionItem.value`
:type: `string`
각 항목을 구분하는 필수 고유 값입니다.
:::
::: api-item
:property: `AccordionItem.disabled`
:type: `boolean`
:default: `false`
해당 항목의 트리거가 상태를 변경하지 못하게 합니다.
:::
::: api-item
:property: `AccordionTrigger.indicator`
:type: `ReactNode`
:default: `Chevron icon`
기본 펼침 표시기를 사용자 정의 콘텐츠로 대체합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
