## 而댄룷?뚰듃 API

:::: api-list
::: api-item
:property: `type`
:type: `single` | `multiple`
:default: `single`
Allows one open item or several open items.
:::
::: api-item
:property: `defaultValue`
:type: string | string[]
Initially open item value. Use a string array with `multiple`.
:::
::: api-item
:property: `AccordionItem.value`
:type: `string`
Required, unique identifier for an item.
:::
::: api-item
:property: `AccordionItem.disabled`
:type: `boolean`
:default: `false`
Prevents its trigger from changing the item.
:::
::: api-item
:property: `AccordionTrigger.indicator`
:type: `ReactNode`
:default: `Chevron icon`
