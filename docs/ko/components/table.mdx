# Table

표 형식 데이터를 표현하는 시맨틱 테이블 구성 요소입니다.

## 가져오기

```tsx
import {
  Table,
  TableBody,
  TableCaption,
  TableCell,
  TableFooter,
  TableHead,
  TableHeader,
  TableRow,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      <TableHead>Status</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Design system</TableCell>
      <TableCell>Ready</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `size`
:type: `xs` | `sm` | `md` | `lg` | `xl`
:default: `md`
테이블의 행 밀도를 지정합니다.
:::
::: api-item
:property: `hoverable`
:type: `boolean`
:default: `false`
마우스를 올린 행을 강조합니다.
:::
::: api-item
:property: `wrapperClassName`
:type: `string`
overflow wrapper에 적용할 class 이름입니다.
:::
::: api-item
:property: `TableHeader`, `TableBody`, `TableRow`, `TableHead`, `TableCell`
:type: `Native element props`
시맨틱 테이블을 구성하는 요소입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
