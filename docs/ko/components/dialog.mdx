# Dialog

집중이 필요한 작업을 위해 현재 흐름을 일시적으로 차단하는 모달 영역입니다.

## 가져오기

```tsx
import { Dialog, DialogToggle, DialogContent, DialogClose } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Dialog>
  <DialogToggle>Open dialog</DialogToggle>
  <DialogContent>
    <h2>Delete project?</h2>
    <p>This action cannot be undone.</p>
    <DialogClose>Cancel</DialogClose>
  </DialogContent>
</Dialog>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Dialog`
:type: `div props`
Dialog의 루트 컨텍스트입니다.
:::
::: api-item
:property: `DialogToggle`
:type: `button props`
Dialog를 열거나 닫습니다.
:::
::: api-item
:property: `DialogContent`
:type: `div props`
모달 콘텐츠 영역입니다.
:::
::: api-item
:property: `DialogClose`
:type: `button props`
현재 열린 Dialog를 닫습니다.
:::
::: api-item
:property: `DialogContent.outEvent`
:type: `boolean`
:default: `false`
배경을 클릭하면 Dialog를 닫습니다.
:::
::: api-item
:property: `DialogContent.hideClose`
:type: `boolean`
:default: `false`
기본 닫기 버튼을 숨깁니다.
:::
::: api-item
:property: `DialogContent.maxWidth`
:type: `number | string`
:default: `450px`
Dialog 콘텐츠의 최대 너비입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
