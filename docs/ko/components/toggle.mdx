# Toggle

서식이나 보기 옵션을 켜고 끄는 두 상태 버튼입니다.

## 가져오기

```tsx
import { Toggle } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Toggle aria-label="Toggle bold">Bold</Toggle>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `selected`
:type: `boolean`
:default: `false`
초기 눌림 상태입니다. 속성이 바뀌면 함께 갱신됩니다.
:::
::: api-item
:property: `size`
:type: `sm` | `md` | `lg`
:default: `md`
Toggle의 크기입니다.
:::
::: api-item
:property: `disabled`
:type: `boolean`
:default: `false`
상호작용을 비활성화합니다. 네이티브 버튼 속성도 지원합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
