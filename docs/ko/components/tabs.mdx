# Tabs

여러 패널 중 한 번에 하나의 섹션만 보여주는 컴포넌트입니다.

## 가져오기

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Tabs defaultValue="overview">
  <TabsList>
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="activity">Activity</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">Project overview</TabsContent>
  <TabsContent value="activity">Recent activity</TabsContent>
</Tabs>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `value`
:type: `string`
외부에서 제어하는 활성 탭 값입니다.
:::
::: api-item
:property: `defaultValue`
:type: `string`
필수 초기 활성 탭 값입니다.
:::
::: api-item
:property: `onValueChange`
:type: `(value: string) => void`
탭이 활성화된 뒤 호출됩니다.
:::
::: api-item
:property: `size`
:type: `xs` | `sm` | `md` | `lg` | `xl`
:default: `md`
탭 컨트롤의 크기입니다.
:::
::: api-item
:property: `TabsTrigger.value`
:type: `string`
패널과 연결되는 필수 값입니다.
:::
::: api-item
:property: `TabsContent.value`
:type: `string`
연결된 트리거와 일치하는 필수 값입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
