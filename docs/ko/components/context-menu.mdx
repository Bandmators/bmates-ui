# ContextMenu

대상의 컨텍스트에서 열리는 동작 메뉴입니다.

## 가져오기

```tsx
import {
  ContextMenu,
  ContextMenuContainer,
  ContextMenuItem,
  ContextMenuProvider,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<ContextMenuProvider>
  <ContextMenuContainer>Right-click me</ContextMenuContainer>
  <ContextMenu>
    <ContextMenuItem>Rename</ContextMenuItem>
    <ContextMenuItem>Delete</ContextMenuItem>
  </ContextMenu>
</ContextMenuProvider>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `ContextMenuProvider.align`
:type: `start` | `center` | `end`
:default: `start`
플로팅 메뉴의 가로 정렬을 지정합니다.
:::
::: api-item
:property: `ContextMenuProvider.space`
:type: `number`
:default: `0`
대상과 메뉴 사이의 간격을 픽셀 단위로 지정합니다.
:::
::: api-item
:property: `ContextMenu.width`
:type: `CSSProperties[width]`
플로팅 메뉴의 너비입니다.
:::
::: api-item
:property: `ContextMenuItem.disabled`
:type: `boolean`
:default: `false`
항목의 동작을 비활성화합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
