# Label

폼 컨트롤에 연결하는 접근 가능한 텍스트 레이블입니다.

## 가져오기

```tsx
import { Label } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Label htmlFor="email">Email address</Label>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `htmlFor`
:type: `string`
레이블을 폼 컨트롤 ID와 연결합니다.
:::
::: api-item
:property: `children`
:type: `ReactNode`
레이블 콘텐츠입니다. 다른 네이티브 label 속성도 지원합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
