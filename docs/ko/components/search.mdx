# Search

트리거, 입력 필드, 검색 결과를 조합할 수 있는 검색 영역입니다.

## 가져오기

```tsx
import {
  Search,
  SearchContent,
  SearchInput,
  SearchInputToggle,
  SearchItem,
  SearchToggle,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Search>
  <SearchToggle>Search</SearchToggle>
  <SearchContent>
    <SearchInput placeholder="Search projects" />
    <SearchItem>Design system</SearchItem>
  </SearchContent>
</Search>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Search`
:type: `children`
Search의 루트 컨텍스트입니다.
:::
::: api-item
:property: `SearchContent.width`
:type: `CSSProperties[width]`
검색 패널의 너비입니다.
:::
::: api-item
:property: `SearchInput`
:type: `input props`
네이티브 검색 입력 필드 속성입니다.
:::
::: api-item
:property: `SearchItem.disabled`
:type: `boolean`
:default: `false`
검색 결과를 선택하지 못하게 합니다.
:::
::: api-item
:property: `align`
:type: `start | center | end`
:default: `center`
검색 패널의 정렬을 지정합니다.
:::
::: api-item
:property: `space`
:type: `number`
:default: `0`
트리거와 패널 사이의 간격을 픽셀 단위로 지정합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
