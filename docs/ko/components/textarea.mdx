# Textarea

긴 텍스트를 입력하는 여러 줄 입력 필드입니다.

## 가져오기

```tsx
import { Textarea } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Textarea rows={4} placeholder="Write a message" aria-label="Message" />
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Textarea`

`value`, `defaultValue`, `placeholder`, `rows`, `disabled`, `required`, `maxLength`, `onChange`를 포함한 모든 네이티브 textarea 속성을 지원합니다.

::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
