# Badge

상태, 분류 또는 개수를 나타내는 간결한 레이블입니다.

## 가져오기

```tsx
import { Badge } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Badge variant="success">Active</Badge>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `variant`
:type: `primary` | `secondary` | `success` | `danger` | `warning` | `info` | `outline` | `ghost`
:default: `primary`
상태 색상을 설정합니다.
:::
::: api-item
:property: `size`
:type: `sm` | `md` | `lg`
:default: `md`
배지 크기를 설정합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
