# Dropdown

간결한 트리거에서 열리는 동작 메뉴입니다.

## 가져오기

```tsx
import {
  Dropdown,
  DropdownContent,
  DropdownItem,
  DropdownToggle,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Dropdown>
  <DropdownToggle>Actions</DropdownToggle>
  <DropdownContent>
    <DropdownItem>Edit</DropdownItem>
    <DropdownItem>Duplicate</DropdownItem>
  </DropdownContent>
</Dropdown>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Dropdown`
:type: `children`
메뉴의 루트 컨텍스트입니다.
:::
::: api-item
:property: `DropdownContent.width`
:type: `CSSProperties[width]`
플로팅 메뉴의 너비입니다.
:::
::: api-item
:property: `DropdownItem.disabled`
:type: `boolean`
:default: `false`
항목을 선택하지 못하게 합니다.
:::
::: api-item
:property: `align`
:type: `start | center | end`
:default: `center`
메뉴의 가로 정렬을 지정합니다.
:::
::: api-item
:property: `space`
:type: `number`
:default: `0`
트리거와 메뉴 사이의 간격을 픽셀 단위로 지정합니다.
:::
::: api-item
:property: `hoverOpen`
:type: `boolean`
:default: `false`
포인터를 올리면 메뉴를 엽니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
