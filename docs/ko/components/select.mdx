# Select

목록에서 하나 이상의 옵션을 선택하도록 조합할 수 있는 컨트롤입니다.

## 가져오기

```tsx
import { Select, SelectToggle, SelectContent, SelectItem } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Select align="start">
  <SelectToggle>Select a country</SelectToggle>
  <SelectContent width="16rem">
    <SelectItem value="kr">Korea</SelectItem>
    <SelectItem value="us">United States</SelectItem>
  </SelectContent>
</Select>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `value`
:type: `SelectType[]`
외부에서 제어하는 선택 옵션입니다.
:::
::: api-item
:property: `defaultValue`
:type: `SelectType[]`
:default: `[]`
비제어 방식에서 사용할 초기 선택 옵션입니다.
:::
::: api-item
:property: `onValueChange`
:type: `(value: SelectType[]) => void`
선택 옵션이 바뀔 때 다음 값과 함께 호출됩니다.
:::
::: api-item
:property: `multi`
:type: `boolean`
:default: `false`
둘 이상의 옵션을 선택할 수 있도록 합니다.
:::
::: api-item
:property: `align`
:type: `start` | `center` | `end`
:default: `center`
콘텐츠 정렬을 지정합니다.
:::
::: api-item
:property: `space`
:type: `number`
:default: `0`
트리거와 목록 사이의 간격을 픽셀 단위로 지정합니다.
:::
::: api-item
:property: `hoverOpen`
:type: `boolean`
:default: `false`
마우스를 올리면 목록을 엽니다.
:::
::: api-item
:property: `SelectItem.value`
:type: `string`
필수 옵션 값입니다.
:::
::: api-item
:property: `SelectItem.disabled`
:type: `boolean`
:default: `false`
옵션을 선택하지 못하게 합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
