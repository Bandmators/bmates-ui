# Pagination

여러 페이지로 구성된 콘텐츠를 이동하기 위한 내비게이션입니다.

## 가져오기

```tsx
import {
  AutoPagination,
  Pagination,
  PaginationLink,
  PaginationPreviousLink,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Pagination>
  <PaginationContent>
    <PaginationPreviousLink />
    <PaginationItem><PaginationLink selected>1</PaginationLink></PaginationItem>
    <PaginationItem><PaginationLink>2</PaginationLink></PaginationItem>
  </PaginationContent>
</Pagination>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `PaginationLink.selected`
:type: `boolean`
:default: `false`
현재 페이지임을 표시합니다.
:::
::: api-item
:property: `PaginationLink.disabled`
:type: `boolean`
:default: `false`
페이지 이동을 비활성화합니다.
:::
::: api-item
:property: `AutoPagination.pageNo`
:type: `number`
필수 현재 페이지 번호입니다.
:::
::: api-item
:property: `AutoPagination.pageSize`
:type: `number`
필수 전체 페이지 수입니다.
:::
::: api-item
:property: `AutoPagination.pageGap`
:type: `number`
:default: `10`
화면에 표시할 최대 페이지 링크 수입니다.
:::
::: api-item
:property: `AutoPagination.linkas`
:type: `React.ElementType`
사용자 정의 링크 컴포넌트입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
