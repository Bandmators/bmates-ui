# Toast

문서 흐름 밖에 일시적으로 표시되는 알림입니다.

## 가져오기

```tsx
import { Toaster, Toast, useToast, ToastData } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
function SaveToast() {
  const { toast } = useToast();
  return (
    <Button
      onClick={() => toast({ title: 'Project saved', variant: 'success' })}
    >
      Show toast
    </Button>
  );
}

<SaveToast />
<Toaster position="bottom-right" />
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `Toaster.position`
:type: `top-left` | `top-center` | `top-right` | `bottom-left` | `bottom-center` | `bottom-right`
:default: `bottom-right`
대기 중인 Toast를 표시할 viewport 위치입니다.
:::
::: api-item
:property: `toast.title`
:type: `ReactNode`
Toast 제목입니다.
:::
::: api-item
:property: `toast.description`
:type: `ReactNode`
Toast 본문 콘텐츠입니다.
:::
::: api-item
:property: `toast.variant`
:type: `default` | `primary` | `secondary` | `success` | `danger` | `warning` | `info`
알림의 시각적 상태입니다.
:::
::: api-item
:property: `toast.time`
:type: `number`
닫히기 전 지연 시간입니다. 음수 값을 사용하면 계속 표시됩니다.
:::
::: api-item
:property: `toast.action`
:type: `(data: unknown) => void`
Toast를 클릭할 때 호출됩니다.
:::
::: api-item
:property: `toast.data`
:type: `unknown`
`action` 콜백에 전달할 사용자 정의 데이터입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
