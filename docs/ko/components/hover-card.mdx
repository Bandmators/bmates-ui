# HoverCard

대상에 마우스를 올렸을 때 표시되는 비모달 미리보기입니다.

## 가져오기

```tsx
import { HoverCard, HoverCardToggle, HoverCardContent } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<HoverCard>
  <HoverCardToggle>@bmates</HoverCardToggle>
  <HoverCardContent>
    <strong>BMates UI</strong>
    <p>A React component library.</p>
  </HoverCardContent>
</HoverCard>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `HoverCard`
:type: `children`
HoverCard의 루트 컨텍스트입니다.
:::
::: api-item
:property: `HoverCardContent.width`
:type: `CSSProperties[width]`
미리보기 영역의 너비입니다.
:::
::: api-item
:property: `HoverCardToggle`
:type: `div props`
마우스를 올렸을 때 미리보기를 여는 대상입니다.
:::
::: api-item
:property: `align`
:type: `start | center | end`
:default: `center`
콘텐츠 정렬을 지정합니다.
:::
::: api-item
:property: `space`
:type: `number`
:default: `16`
트리거와 콘텐츠 사이의 간격을 픽셀 단위로 지정합니다.
:::
::: api-item
:property: `openDelay`
:type: `number`
:default: `500`
열리기 전 지연 시간을 밀리초 단위로 지정합니다.
:::
::: api-item
:property: `closeDelay`
:type: `number`
:default: `200`
닫히기 전 지연 시간을 밀리초 단위로 지정합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
