# Checkbox

서로 독립적인 옵션을 하나 이상 선택하는 컨트롤입니다.

## 가져오기

```tsx
import { Checkbox } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Checkbox defaultChecked>Send me product updates</Checkbox>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `checked`
:type: `boolean`
외부에서 제어하는 선택 상태입니다.
:::
::: api-item
:property: `defaultChecked`
:type: `boolean`
:default: `false`
비제어 방식에서 사용하는 초기 선택 상태입니다.
:::
::: api-item
:property: `onCheckedChange`
:type: `(checked: boolean) => void`
선택 상태가 바뀔 때마다 호출됩니다.
:::
::: api-item
:property: `label`
:type: `string`
컨트롤 옆에 표시할 텍스트입니다.
:::
::: api-item
:property: `align`
:type: `start` | `center` | `end`
:default: `center`
체크 박스와 레이블의 세로 정렬을 지정합니다.
:::
::: api-item
:property: `iconEl`
:type: `ReactNode`
사용자 정의 체크 표시 콘텐츠입니다.
:::
::: api-item
:property: `disabled`
:type: `boolean`
:default: `false`
상호작용을 비활성화합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
