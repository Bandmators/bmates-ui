# Card

관련 콘텐츠와 동작을 하나의 영역으로 묶는 컨테이너입니다.

## 가져오기

```tsx
import {
  Card,
  CardBody,
  CardDesc,
  CardFooter,
  CardHead,
  CardTitle,
} from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Card>
  <CardHead>
    <CardTitle>Project status</CardTitle>
    <CardDesc>Updated just now</CardDesc>
  </CardHead>
  <CardBody>All systems are operational.</CardBody>
</Card>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `width`
:type: `number`
루트 Card 너비를 픽셀 단위로 설정합니다.
:::
::: api-item
:property: `CardHead`, `CardBody`, `CardFooter`
:type: `div props`
헤더, 본문, 푸터를 구성하는 레이아웃 영역입니다.
:::
::: api-item
:property: `CardTitle`, `CardDesc`

:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
