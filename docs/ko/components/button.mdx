# Button

명확한 위계와 상태를 제공하는 동작 컨트롤입니다.

## 가져오기

```tsx
import { Button } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<Button variant="primary">Save changes</Button>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `variant`
:type: `default` | `primary` | `secondary` | `success` | `danger` | `warning` | `info` | `outline` | `ghost`
:default: `default`
시각적 스타일입니다. `default`, `secondary`, `success`, `danger`, `warning`, `info`, `outline`, `ghost`를 사용할 수 있습니다.
:::
::: api-item
:property: `size`
:type: `sm` | `md` | `lg` | `icon`
:default: `md`
버튼의 높이와 내부 여백을 조절합니다.
:::
::: api-item
:property: `full`
:type: `boolean`
:default: `false`
버튼이 컨테이너 너비를 채우도록 합니다.
:::
::: api-item
:property: `disabled`
:type: `boolean`
:default: `false`
상호작용을 비활성화합니다. `type`, `onClick`을 포함한 네이티브 버튼 속성도 지원합니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
