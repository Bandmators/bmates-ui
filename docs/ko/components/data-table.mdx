# DataTable

클라이언트 측 정렬, 필터링 및 행 선택을 지원하는 데이터 테이블입니다.

## 가져오기

```tsx
import { DataTable } from 'bmates-ui';
```

## 기본 사용법

아래 예제는 기본 Storybook 구성을 바탕으로 하며 구현을 시작할 때 활용할 수 있습니다.

```tsx
<DataTable
  columns={[
    { id: 'name', header: 'Name', accessor: row => row.name, sortable: true },
    { id: 'role', header: 'Role', accessor: row => row.role },
  ]}
  data={[
    { id: 'jane', name: 'Jane Doe', role: 'Designer' },
    { id: 'sam', name: 'Sam Lee', role: 'Engineer' },
  ]}
  getRowId={row => row.id}
  filterable
/>
```

## 컴포넌트 API

:::: api-list
::: api-item
:property: `columns`
:type: `DataTableColumn<T>[]`
`id`, `header`와 선택적인 `accessor`, `cell`, `sortable`을 포함하는 필수 열 정의입니다.
:::
::: api-item
:property: `data`
:type: `T[]`
필수 행 데이터입니다.
:::
::: api-item
:property: `getRowId`
:type: `(row: T) => string`
각 행을 안정적으로 구분하는 필수 식별자입니다.
:::
::: api-item
:property: `selectable`
:type: `boolean`
:default: `false`
행 선택 컨트롤을 표시합니다.
:::
::: api-item
:property: `filterable`
:type: `boolean`
:default: `false`
클라이언트 측 필터 입력 필드를 표시합니다.
:::
::: api-item
:property: `filterPlaceholder`
:type: `string`
:default: `Filter rows...`
필터 입력 필드의 placeholder입니다.
:::
::: api-item
:property: `emptyMessage`
:type: `ReactNode`
:default: `No matching rows.`
일치하는 행이 없을 때 표시할 콘텐츠입니다.
:::
::: api-item
:property: `selectedRowIds`
:type: `string[]`
외부에서 제어하는 선택 상태입니다.
:::
::: api-item
:property: `onSelectedRowIdsChange`
:type: `(rowIds: string[]) => void`
선택 상태가 변경될 때 호출됩니다.
:::
::: api-item
:property: `defaultSelectedRowIds`
:type: `string[]`
:default: `[]`
비제어 방식에서 처음 선택할 행 ID 목록입니다.
:::
::: api-item
:property: `className`
:type: `string`
루트 요소에 추가할 class 이름입니다.
:::
::::

## 사용 참고사항

- 문서에 표시된 모든 컴포넌트는 `bmates-ui`에서 내보냅니다.
- 별도 설명이 없다면 각 컴포넌트는 기반 HTML 요소의 표준 속성도 지원합니다.
- 애플리케이션이 상태를 관리한다면 `default*` 속성만 사용하지 말고 제어 값과 변경 핸들러를 함께 사용합니다.
