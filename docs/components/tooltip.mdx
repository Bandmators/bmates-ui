# Tooltip

A short, non-interactive description for a control.

## Import

```tsx
import { Tooltip } from 'bmates-ui';
```

## Basic usage

The example below mirrors the primary Storybook composition and can be used as a starting point.

```tsx
<Tooltip content="Save the current changes">
  <Button aria-label="Save">Save</Button>
</Tooltip>
```

## Component API

:::: api-list
::: api-item
:property: `message`
:type: `string`
Required tooltip text.
:::
::: api-item
:property: `direction`
:type: `top` | `bottom` | `left` | `right`
:default: `top`
Side on which the tooltip is displayed.
:::
::: api-item
:property: `children`
:type: `ReactNode`
Tooltip target element.
:::
::::

## Usage notes

- Every component in the table is exported from `bmates-ui`.
- Unless noted otherwise, a component also accepts the standard props of its underlying HTML element.
- For application-owned state, use a controlled value and its change handler instead of only a `default*` prop.
