# BMatesProvider

The provider that supplies the library theme and shared styling context.

## Import

```tsx
import { BMatesProvider } from 'bmates-ui';
```

## Basic usage

The example below mirrors the primary Storybook composition and can be used as a starting point.

```tsx
<BMatesProvider>
  <Button>Ready</Button>
</BMatesProvider>
```
