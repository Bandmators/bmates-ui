# Textarea

A multi-line field for longer text input.

## Import

```tsx
import { Textarea } from 'bmates-ui';
```

## Basic usage

The example below mirrors the primary Storybook composition and can be used as a starting point.

```tsx
<Textarea rows={4} placeholder="Write a message" aria-label="Message" />
```

## Component API

:::: api-list
::: api-item
:property: `Textarea`
:type: `React.ComponentPropsWithoutRef<'textarea'>`
Accepts every native textarea prop, including `value`, `defaultValue`, `placeholder`, `rows`, `disabled`, `required`, `maxLength`, and `onChange`.
:::
::::

## Usage notes

- Every component in the table is exported from `bmates-ui`.
- Unless noted otherwise, a component also accepts the standard props of its underlying HTML element.
- For application-owned state, use a controlled value and its change handler instead of only a `default*` prop.
